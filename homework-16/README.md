# ДЗ №16 — Angular и TypeScript

Самостоятельный учебный проект в папке homework-16 репозитория product-card.
Это новый каркас Angular, не копия репозитория преподавателя.

Решения пиши в src/app/training.ts. Файл уже подключён в app.component.ts.
Порядок разделов: интерфейсы → переменные и типы → функции → массивы.
Условия пунктов №3–10 записаны комментариями. Решения нужно написать самостоятельно.

## Запуск

Из папки product-card в терминале VS Code:

```powershell
cd homework-16
npm.cmd start
```

Открой http://localhost:4200. Результаты console.log видны в F12 → Console.
При сохранении training.ts приложение обновляется автоматически.
Остановка сервера: Ctrl+C.

## Проверка перед сдачей

```powershell
npm.cmd run build
```

Зависимости уже установлены на этом компьютере. После клонирования на другой
компьютер выполни npm.cmd ci в папке homework-16.
node_modules, dist и .angular исключены из Git.
